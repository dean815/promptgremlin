# general: anything that fits no other type

## Slots
1. **goal** (high): what must be true when the work is done.
2. **output** (high): what comes back, in what form and length.
3. **constraints** (medium): scope limits, things to leave alone, style.
4. **inputs** (medium): files, links, pasted material.
5. **why** (low): the motivation, if the person wants to give it.

## Prompt skeleton
Context from the brief → task → constraints → inputs → output → stop line.
