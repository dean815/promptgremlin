# promptgremlin

![promptgremlin: a gremlin turning crumpled notes into structured prompts](https://github.com/dean815/promptgremlin/releases/download/v3.2.2/promptgremlin-banner.webp)

promptgremlin turns a thin request for real work into a targeted, paste-ready prompt for any
of 33 supported AI models and tools. It asks the few questions that would change the result, each with
a suggested answer, then writes the prompt to that vendor's current official guidance.

## Install

Claude Code (marketplace):

    claude plugin marketplace add dean815/promptgremlin
    claude plugin install promptgremlin@promptgremlin
