# judgment: a typed decision (Jev and similar)

## Slots
1. **decision** (high): the question and the allowed answers (labels, scale).
2. **inputs** (high): what the judge sees (email text, record fields).
3. **edge cases** (medium): inputs that fit no label; ties.
4. **calibration** (low): examples per label, if the person has them.

The Jev target notes define the JSON spec; fill it from the brief.
