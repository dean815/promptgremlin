## All models
- Manus has no official prompting guide. The sources are a beginner prompt blog post and the Projects feature page, so the rest is thin, light-touch guidance. (hand-written: no official guide)
- Describe the deliverable and the finish line, not the steps: what exists when it is done, who it is for, what format, and what counts as finished. Manus works over multiple steps by itself. (beginner-prompts#How to Use These Prompts; hand-written: deliverable-over-steps framing)
- For ongoing work, say so in plain words: ask it to own the outcome, keep tracking, follow up, and walk the user through. The vendor says wording like that is what makes Manus behave as an agent instead of a chatbot. (beginner-prompts#Key Tip for Agent Prompts)
- Tell it when to stop and ask. Say which decisions need the user, and when it may ask questions first (one at a time for forms and paperwork) or proceed on its own. (beginner-prompts#Life Admin Agents, #Daily Life Automation; hand-written: ask-or-proceed split)
- If the goal is unclear, give the situation and let Manus figure out what needs doing and ask for missing info, instead of padding the prompt with guessed requirements. (beginner-prompts#When You're Not Sure What to Ask)
- Fill concrete details (topic, goal, event, deadline) where the task has them, and leave nothing in square brackets. (beginner-prompts#How to Use These Prompts)
- Recurring work belongs in a Project: its master instruction and knowledge base apply to every new task in it. Standing rules go there, so the task prompt is only what differs this time. (projects#What it is, #Tips)
- If asked to write a master instruction, make it specific and detailed so each task needs less context, and name it for the kind of work. Knowledge-base files apply only to tasks created after the change, while instruction edits apply from the next message. (projects#Tips, #Configuration Updates)
- Projects and tasks are private by default; invitees see the shared instruction and files, not other people's tasks. Do not put anything sensitive in a master instruction meant to be shared. (projects#Collaboration and Privacy)
